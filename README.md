# Fuck Daily Routines

Fuck Daily Routines, the **free** version of DR that grants access to **all** premium features **without** payment, authentication, spyware, or any unnecessary data collection, including some extra added features of my own. 

Which makes this not only a **better** version of the original DR, but a **safer** one too that respects your privacy and doesn't expect you to pay in order to gain access to the full package.

This is my first time editing/making a plugin, let me know if there are any bugs by opening an issue or contacting me on my disc: sure_ah. Feel free to request new features or make suggestions as well.

## Installation

- Open Dalamud Settings by typing `/xlplugins` in game, then go to the Experimental tab and select Custom Plugin Repositories.
- Add this repository URL:

   ```text
   https://raw.githubusercontent.com/shura-m/FuckDailyRoutines/main/FuckDailyRoutines.json
   ```

- Click on save at the bottom right, then look for and install **Fuck Daily Routines**
